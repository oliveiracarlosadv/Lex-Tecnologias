Orientações

Orientações gerais de uso

O que vale para todos os sistemas: primeira abertura, segurança dos dados, atualização e suporte.

Primeira abertura (aviso de segurança)

Os instaladores ainda não têm assinatura digital paga da Apple e da Microsoft. Por isso, na primeira vez, o sistema pode avisar que o desenvolvedor não foi identificado:

Mac

Abra Ajustes do Sistema → Privacidade e Segurança, role até o fim e clique em Abrir Mesmo Assim. Outra forma: botão direito no app → Abrir.

Windows

Na tela “O Windows protegeu o computador”, clique em Mais informações → Executar assim mesmo.

Android

Permita a instalação “desta fonte” (navegador ou gerenciador de arquivos) e toque em Instalar.

iPhone

Aplicativos web: abra o endereço no Safari → Compartilhar → Adicionar à Tela de Início.

Seus dados ficam com você

  • Os sistemas guardam os dados no seu computador ou no navegador do seu aparelho, sem servidor da Lex no meio.
  • Faça backup regularmente pelos botões de cada sistema e guarde uma cópia fora do computador.
  • Nos aplicativos web, os dados ficam no navegador daquele aparelho: limpar os dados do navegador apaga as informações.

Sigilo profissional e LGPD

Você é o controlador dos dados dos seus clientes. Use os sistemas com finalidade legítima e base legal, especialmente os que pesquisam terceiros (Lex Detetive). Ao ligar uma IA na nuvem, os textos enviados para análise saem do computador.

Ferramentas de apoio

Prazos calculados, sugestões e resumos por IA são auxiliares. A conferência nos autos e nos diários oficiais continua sendo do advogado.

Conferir um download

Quando a versão traz o arquivo SHA256SUMS.txt, confira no Terminal: shasum -a 256 -c SHA256SUMS.txt (Mac) ou Get-FileHash arquivo (Windows).

Atualizar

Instale a versão nova por cima da anterior. Os sistemas que guardam dados no computador fazem backup antes de atualizar.

Pedir acesso ou ajuda

Para sistemas de distribuição restrita, use Solicitar acesso (é preciso uma conta gratuita no GitHub). Informe o sistema, o seu sistema operacional e como pretende usar.
