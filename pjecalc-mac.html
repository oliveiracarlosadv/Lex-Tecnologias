PJe-Calc Cidadão para Mac

O programa oficial de cálculos trabalhistas da Justiça do Trabalho, instalado no Mac como aplicativo do sistema.

Baixar o instalador para MacInstruções completas
SituaçãoNão oficial
Versão2.16.0
PlataformasMac (Apple Silicon e Intel)
PreçoGratuito
O que faz

Recursos principais

  • Instala o PJe-Calc Cidadão 2.16.0 em Aplicativos, com o Java já incluído, e o ícone PJe no Dock.
  • O ícone do Dock liga e desliga o sistema; a janela abre no Chrome (ou no Safari).
  • Os arquivos do PJe-Calc são os originais do instalador oficial, sem alteração.
Telas

Telas

As telas deste sistema serão publicadas em breve. Para uma demonstração, use Solicitar acesso.

Manual

Como instalar e começar

  1. Baixe pjecalc-2.16.0-instalador-mac.pkg e dê dois cliques (Continuar, Instalar, Fechar).
  2. Clique no ícone PJe no Dock para ligar.
  3. Atualize as Tabelas Auxiliares após a primeira instalação.
  4. Os cálculos ficam em ~/PJe-Calc/pjecalc-2.16.0: faça cópia de segurança.
Importante: Projeto independente e não oficial. O PJe-Calc Cidadão é desenvolvido e distribuído pela Justiça do Trabalho (TRT da 8ª Região / CSJT). Confira os cálculos antes de usá-los em processo.
