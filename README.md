## Sobre

Criado por **Carlos Alexandre Albuquerque Oliveira**, advogado em Belém/PA. As telas usam dados fictícios. O PJe-Calc Cidadão para Mac e o AMT Desktop são projetos independentes, sem vínculo com a Justiça do Trabalho e com a Intelbras.

O site é feito só de HTML, CSS e um pouco de JavaScript; para alterar textos, edite os arquivos `.html`.
